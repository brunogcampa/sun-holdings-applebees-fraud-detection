# Notebooks Databricks

Ejecutar en orden: `00_setup_catalog.py`, `00_extract_source_data.py`, `01_eda_applebees.py`. Los archivos fuente tienen marcadores Databricks; las copias IPYNB sin outputs están en `import/` para importación individual desde la web.

Los widgets se configuran al principio; todas las celdas dependen de las anteriores. Las tablas reciben nombres nuevos por ejecución. Ver [instrucciones](../docs/carga_free_edition.md) y [validación](../docs/data_quality.md).
